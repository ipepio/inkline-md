Archivos

Tu carpeta de trabajo y las operaciones con documentos locales.

Carpeta raíz
Cambia el workspace de Markdown visible en el explorador.
Confirmar al cerrar cambios
Advertir si un documento tiene modificaciones sin guardar.
El prototipo permite guardar en navegadores compatibles mediante File System Access. La escritura atómica real, recuperación ante fallos y detección de conflictos necesitan la implementación nativa con Tauri/Rust.

Exportación

Diferenciamos guardar el archivo fuente, descargar una copia y publicar el resultado.

Tamaño de página
Se aplica al diálogo de impresión / Guardar PDF.
Exportar HTML
Un solo archivo con estilos, código resaltado y diagramas renderizados.
Imprimir / Guardar PDF
Abre la ventana del sistema para imprimir o guardar como PDF.
Descargar Markdown crea una copia .md; Guardar escribe en el archivo original cuando existe un permiso de escritura. Exportar HTML y PDF no sustituyen al documento fuente.
